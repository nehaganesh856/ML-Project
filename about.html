EcoSense ML Portal

EcoSense ML is an academic full-stack prototype designed for second-year college students. It demonstrates the integration of machine learning pipelines inside responsive web interfaces to solve environmental challenges. The system implements real-time loading of household electricity datasets, calculates carbon footprint equivalents, trains regression/clustering models, isolates consumption anomalies, and generates personalized conservation recommendations.

Integrated Machine Learning Models

The application deploys 5 distinct ML architectures to process the power data:

  • Random Forest Regressor (Supervised): Predicts energy load for the next hour using engineered lag variables and moving averages.
  • XGBoost Regressor (Supervised): Uses gradient-boosted decision trees to forecast immediate household load indices.
  • LSTM Neural Network (Supervised Sequence): Built using TensorFlow Keras. Leverages historical sequences of load draws to perform multi-step forecasts for the next 24 hours.
  • K-Means Clustering (Unsupervised): Groups daily/hourly consumption patterns into distinct user segments (Low, Moderate, and High load) to establish profile centroids.
  • Isolation Forest (Unsupervised Anomaly): Measures the isolation distance of active load profiles to flag load spikes and heavy appliance draws without requiring annotated training labels.

Technology Stack

  • Backend Architecture: Python, Flask Microframework, SQLAlchemy ORM
  • Database: SQLite database system (self-generating file structure)
  • Frontend UI System: Vanilla HTML5, CSS3 Grid/Flexbox/Glassmorphism theme, Chart.js for graphs
  • Machine Learning Engines: Pandas, NumPy, scikit-learn, XGBoost, TensorFlow Keras
