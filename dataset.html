UCI Dataset Information & Guide

This application is built to load the Individual Household Electric Power Consumption dataset from the UCI Machine Learning Repository. The raw dataset contains almost 2,075,259 minutely electrical measurements. The columns must contain standard titles: Date, Time, Global_active_power, Global_reactive_power, Voltage, Global_intensity, Sub_metering_1, Sub_metering_2, Sub_metering_3.

During import, our backend pipeline parses datetimes, fills missing fields using forward-fills, clips anomalous household voltage levels, calculates aggregated hourly averages to compile energy consumptions (kWh) and carbon footprints (kg CO₂), and updates the SQLite tables.
